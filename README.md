# 🎵 Spotify Most Streamed Artists – Data Analysis

## 📌 Project Overview

This project focuses on exploring and understanding a dataset of the most streamed artists on Spotify using Python. It involves data inspection, exploratory data analysis (EDA), and data preprocessing to understand artist information and streaming patterns.

The project aims to explore artist demographics, music genres, countries, debut years, and streaming statistics.

## 📊 Dataset Information

- **Dataset:** Most Streamed Artists on Spotify (17_07_2026) V1.1
- **Total Records:** 500
- **Total Features:** 10
- **File Format:** CSV

### Dataset Features

| Column | Description |
|---|---|
| Artist Name | Name of the music artist |
| Sex | Artist's sex |
| Country of Origin | Artist's country |
| Primary Language | Main language of the artist |
| Primary Genre | Main music genre |
| Artist Type | Type of artist |
| Debut Year | Year of musical debut |
| Total Streams (in millions) | Total Spotify streams |
| Lead Streams (in millions) | Streams as lead artist |
| Feature Streams (in millions) | Streams as featured artist |

## 🛠️ Technologies & Libraries Used

- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization

## 🔍 Project Workflow

### 1. Data Loading
- Imported the dataset using Pandas.
- Loaded the CSV file into a DataFrame.

### 2. Data Understanding
- Displayed the first few records.
- Checked dataset dimensions.
- Examined column names and data types.
- Generated descriptive statistics.

### 3. Data Cleaning
- Checked missing values.
- Identified duplicate records.
- Examined columns containing missing information.

### 4. Exploratory Data Analysis (EDA)
The dataset can be explored to understand:
- Most streamed artists.
- Distribution of music genres.
- Artist distribution by country.
- Streaming patterns.
- Lead streams vs. feature streams.
- Artist debut year trends.
